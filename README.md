# Space Week Student Platform

منصة أسبوع الفضاء للطلبة — Production v1.0.0

هذا المستودع خاص ويحتوي حزمة المنصة الإنتاجية وملحق WordPress. سيتم تطوير المتطلبات لاحقًا وفق مواصفات المسابقة الطلابية الفضائية المعتمدة.

## النسخة الحالية
- PHP 8.2+
- MySQL / MariaDB
- Student / Admin authentication
- مشروع واحد لكل طالب في النسخة الحالية
- رفع ملفات خاص وآمن
- سجل تدقيق وصلاحيات وحماية CSRF والجلسات
