# Space Competition Student Platform V2

منصة **المسابقة الطلابية الفضائية** بهوية مؤسسية علمية للجمعية الفلكية الأردنية، موجهة لنحو **300 طالب وطالبة من الصفين التاسع والعاشر**. تدعم البنية الجديدة المشاركة الفردية أو فريقًا من **2–3 طلاب**، المعلم المشرف، مسارين علميين، مواد تعليمية، مشاريع متعددة الأنواع، التعهد، والمراجعة النهائية قبل الإرسال.

## المساران المعتمدان

1. **صمم رحلتك الفضائية من الأرض إلى المريخ**.
2. **كيف تعمل الصواريخ الفضائية؟**.

## V2 Foundation

الفرع `v2-foundation-public` يحتوي المعاينة البصرية الآمنة لوثائق V2، بينما الحزمة الكاملة محفوظة كإصدار قابل للتنزيل وإعادة التجميع. المعاينة لا تحتوي بيانات طلبة أو كلمات مرور أو رفع ملفات.

## الإنتاج

- PHP 8.2+
- MySQL / MariaDB عبر PDO
- HTTPS إلزامي
- Document Root: `public/`
- تخزين خاص خارج الويب العام متى كان ذلك ممكنًا
- الهجرات: `001_schema.sql` ثم `002_competition_v2.sql`

## الخصوصية

لا تضع في GitHub: `.env`، قوائم الطلبة الرسمية، كلمات المرور، تواريخ الميلاد، أرقام الهواتف، صور الطلبة، ملفات المشاريع، السجلات التشغيلية أو النسخ الاحتياطية.

## التحقق

تم التحقق من V2 Foundation محليًا عبر **50 اختبار PHP ناجحًا**، Frontend smoke checks، وفحص Syntax لجميع ملفات PHP، إضافة إلى HTTP smoke للصفحة الرئيسية ومساري المسابقة و404.
