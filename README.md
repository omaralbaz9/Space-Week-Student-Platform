# Space Competition Student Platform V2

منصة **المسابقة الطلابية الفضائية** بهوية مؤسسية علمية للجمعية الفلكية الأردنية، موجهة لنحو **300 طالب وطالبة من الصفين التاسع والعاشر**. تدعم المشاركة الفردية أو فريقًا من **2–3 طلاب**، المعلم المشرف، مسارين علميين، مواد تعليمية، ملفات وروابط مشاريع، التعهد، المراجعة النهائية، ولوحة إدارة V2.

## المساران المعتمدان

1. **صمم رحلتك الفضائية من الأرض إلى المريخ**.
2. **كيف تعمل الصواريخ الفضائية؟**.

## ما يتضمنه V2

- واجهة رسمية Premium Institutional Space Design بالعربية وRTL.
- Mission Control للطالب ومسار مشاركة من 7 مراحل.
- فردي أو فريق 2–3 طلاب مع قواعد أهلية من الخادم.
- معلم مشرف ومساران علميان ومكتبة مواد تعليمية مدارة.
- صور خاصة للمشارك/الفريق وملفات مشاريع خاصة.
- MP4 بحد أقصى 3 دقائق مع تحقق Server-side.
- فحص DOCX/PPTX كبنية OpenXML لمنع ZIP المتنكر.
- لوحة إدارة V2، فلترة، تفاصيل المشاركات، إعادة فتح، CSV آمن، وسجل تدقيق.
- استيراد CLI حتى 300 حساب طالب/طالبة دون إنشاء مشاريع V1.

## الإنتاج

- PHP 8.2+
- MySQL / MariaDB عبر PDO
- HTTPS إلزامي
- Document Root: `public/`
- التخزين الخاص خارج الويب العام متى أمكن
- الهجرات: `001_schema.sql` ثم `002_competition_v2.sql`
- `APP_ENV=production` و`APP_DEBUG=false`

## الخصوصية

لا تضع في GitHub: `.env`، قوائم الطلبة الرسمية، كلمات المرور، تواريخ الميلاد، أرقام الهواتف، صور الطلبة، ملفات المشاريع، سجلات التشغيل أو النسخ الاحتياطية. بيانات الطلبة القُصّر وملفاتهم ليست عامة.
